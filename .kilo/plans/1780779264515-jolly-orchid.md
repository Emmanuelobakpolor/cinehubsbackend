# Plan: Make CinehubsAdmin Dashboard Mobile-Responsive

## Current State Analysis

The admin dashboard (`cinehubsadmin/`) is a TanStack Start + React + Tailwind v4 SPA with:
- **Sidebar**: Fixed left sidebar (w-64 or collapsed w-16), always visible
- **Topbar**: Contains search, notification bell, and user profile dropdown
- **Pages**: Dashboard, Movies, Categories, Subscribers, Broadcast, Upload Movie
- **Current responsive issues**:
  - Sidebar is `fixed left-0` with no mobile toggle/hide behavior
  - Main content has hardcoded `ml-64`/`ml-[4.5rem]` margin-left, breaking on small screens
  - Tables use fixed column grids (`grid-cols-[80px_1.6fr_1fr_...]`) with no mobile stacking
  - Topbar uses `hidden sm:block` for user info, but overall layout doesn't collapse for mobile
  - No hamburger menu / mobile sidebar drawer
  - Modals likely overflow on small screens without proper scrolling

## Implementation Plan

### 1. Create Mobile Sidebar Drawer (New: `MobileSidebar.tsx`)
- Create `cinehubsadmin/src/components/admin/MobileSidebar.tsx`
- Slide-in drawer from left, triggered by hamburger button
- Overlay backdrop that closes on tap
- Same nav items as current Sidebar but optimized for mobile (larger touch targets)
- Uses Radix Dialog or manual portal with fixed positioning
- Animated with transform transitions

### 2. Update Layout (`_layout.tsx`)
- Add `isMobile` state using window width (`useState` + `useEffect` with `matchMedia`)
- On mobile (<768px): hide fixed sidebar, show hamburger button in Topbar
- On desktop (>=768px): show sidebar as-is, hide hamburger
- Adjust `main` margin: remove hardcoded `ml-64`/`ml-[4.5rem]`; on mobile use `ml-0`
- Pass `isMobile` and `menuOpen` state to Topbar

### 3. Update Topbar (`Topbar.tsx`)
- Add `hamburgerOpen` state + `onHamburgerToggle` callback prop
- Show hamburger icon (Menu from lucide) when `isMobile` is true
- Move notification bell and user dropdown closer together on mobile
- Reduce padding on mobile (`px-4 py-3` instead of `px-6 py-4`)
- Search input: on mobile, show icon-only button that expands to full search on tap

### 4. Responsive Tables — All Pages
Replace fixed grid templates with mobile-friendly patterns:

**Dashboard (`_layout.dashboard.tsx`)**:
- Movies table: switch to stacked card layout on mobile (each movie becomes a card with thumbnail, title, status, badge stacked vertically)
- Stats cards: already use `grid-cols-1 md:grid-cols-2 xl:grid-cols-4` ✅ (good)
- Right column plans: stack below movies table on mobile

**Movies (`_layout.movies.tsx`)**:
- Header row: hide on mobile
- Table rows: become cards with vertical layout on mobile (`flex flex-col gap-2`)
- Action menu: keep as `MoreHorizontal` button per card

**Categories (`_layout.categories.tsx`)**:
- Header row: hide on mobile; show "Add Category" as floating action button (FAB) or inline
- Table rows: stack as cards with Edit/Delete buttons visible horizontally
- Edit menu: replace dropdown with inline action buttons on mobile

**Subscribers (`_layout.subscribers.tsx`)**:
- Stats pills: wrap properly (already `flex-wrap`, reduce `min-w` on mobile)
- Table: become scrollable cards or stacked list on mobile
- Columns collapse into expandable rows or stacked fields
- Pagination: keep visible but compact

**Broadcast (`_layout.broadcast.tsx`)**:
- Grid cards are already responsive (`grid-cols-2 md:grid-cols-3 xl:grid-cols-4`) ✅
- Ensure modal fits on mobile (already `max-w-md`, check for scroll)

**Upload Movie (`_layout.upload-movie.tsx`)**:
- Stat cards: already responsive ✅
- CTA area: ensure full-width on mobile

### 5. Update Styles (`styles.css`)
- Add mobile-specific styles for sidebar drawer animation
- Ensure `main.main-content` transition works with dynamic margin
- Add safe-area-inset padding for notched phones
- Ensure scroll containers have `-webkit-overflow-scrolling: touch`
- Mobile sidebar: `transform -translate-x-full` → `translate-x-0` for open state

### 6. Modals & Overlays
- Add `max-h-screen` + `overflow-y-auto` to all modal content divs
- Ensure `p-4` on mobile, `fixed inset-0` covers full screen
- Broadcast modal, AddMovieModal, Category modals: reduce padding on small screens
- Test z-index stacking (sidebar z-30, modals z-[9999])

### 7. Touch Target Improvements
- All interactive elements ≥ 44×44px on mobile
- Increase padding on buttons in table/card views for thumb reach
- Add `active:scale-[0.98]` feedback to touchable elements (already present on some)

### 8. Responsive Utility Classes Summary (search & replace pattern)
Every file needs review for:
- `fixed left-0` → conditional based on mobile (`hidden md:flex`)
- `w-64` / `w-16` → desktop only classes + mobile drawer
- `ml-64` / `ml-[4.5rem]` → `md:ml-64` with `ml-0` default
- Fixed grid columns (`grid-cols-[80px_...]`) → responsive variants
- Large padding (`px-6 py-5`) → compact on mobile (`px-4 py-4`)
- `w-80` dropdowns → `w-[calc(100vw-2rem)] max-w-80` on mobile
